The interaction EIP-8272 does change, with EIP-7825's gas limit cap, is covered by test_reference_intrinsic_gas_boundary.
opcode/test/execution_context/staticcall = A VERIFY frame executes in a static context, and test_verify_frame_binds_reference reads all three reference fields inside one; the general static-context ban rules belong to EIP-8141.
general/code_coverage/eels = Filling this suite through the EELS t8n executes every line EIP-8272 adds to the reference implementation on the read side: the reference type and its two derivations, check_recent_root_references and both of its rejection branches, the intrinsic-cost additions on both the standard and the floor branch, the pre-warming of the contract and its keys, the RECENTROOTREFLOAD implementation with all three field branches and both halt branches, and TXPARAM index 0x0F.
general/code_coverage/test_coverage = Every parametrized arm of this suite fills into a fixture with a discriminating post-state, and the suite is mutation-checked against the reference implementation: removing the once-only address charge, the reference term from the calldata floor, the reference bytes from the floor byte count, or replacing the window check with a subtract-before-compare form each fails arms of this suite.
general/code_coverage/missed_lines = The only lines of EIP-8272 with no runtime are those of the write path, which the specification leaves as RECENT_ROOT_CODE = TBD; the reference implementation installs no code at RECENT_ROOT_ADDRESS, so no fixture can reach them.
