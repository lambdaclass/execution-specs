# EIP-7906 Transaction Assertions Test Cases

One row per test function in this directory. `Setup` names the
parametrized arms; a test with no arms is a single case. Rule ids refer
to the rule inventory the suite was written from, and each is cited in
the function's docstring next to the assertion that pins it.

Every expectation is derived by hand from the pinned spec revision
`690fc1d2f7a765dae9d388d51548cafe5cb1da40` — gas values as the frame
entry charge plus `bytecode.gas_cost(fork)`, diff values by re-deriving
the spec's enumeration rules in Python — and nothing imports the
reference implementation.
